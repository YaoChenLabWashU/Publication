PURPOSE
-------
Plots transition-triggered FLiP lifetime (zeroed, not Z-scored) across four
brain regions (Dorsal CA1, Motor Cortex, Visual Cortex, mPFC) using FLIM-mAKAR,
comparing experimental to shuffled data within each region. Also runs nested
statistical analyses (experimental vs shuffled) per region. Produces Extended
Data Figure 3 for the manuscript.

--------------------------------------------------------------------------------
PROCESSING PIPELINE
--------------------------------------------------------------------------------

Raw .mat files (per brain region)
  |
  +--> choose_excluded_acqs()
  |      first_acqs = 3; baseline_idxs from FLiP_Experiment_Summary.xlsx.
  |
  +--> build_classes()   [called per region, with p2=True]
  |      Constructs FLiPExperiment objects.
  |      |
  |      +--> FLiPExperiment()  [called internally]
  |             Loads/processes concatenated .mat file; extracts FLiP lifetime,
  |             sleep states, microarousal labeling.
  |
  +--> transition_triggered_lifetime()   [called per region, with shuffled=True]
  |      Aligns zeroed FLiP lifetime to sleep state transitions.
  |      Transitions: NREM-Wake, REM-Wake, Microarousals, Wake-NREM, NREM-REM
  |      Window: 50 s before → 150 s after
  |      Splits Wake-NREM by preceding bout length (cutoff: 100 s)
  |      Splits NREM-Wake by preceding bout length (cutoff: 70 s)
  |      Includes shuffled photometry in same figure
  |      Returns: fig_dict, lifetime_dict (per region)
  |
  +--> transition_triggered_quant()
  |      Quantifies amplitude in specified post-transition windows.
  |
  +--> nested_analysis_stats_v2()
         Stage 1: robust HuberT per-animal means (experimental vs shuffled, paired).
         Stage 2: sign permutation (primary) + Welch t-test or paired t-test (secondary).
         Note: mPFC uses perm_flag=False due to n_animals > threshold.

KEY PARAMETERS
--------------------------------------------------------------------------------

  Parameter              Value           Meaning
  ---------------------  --------------  ----------------------------------------
  epoch_len              4 s             Sleep scoring epoch length
  microarousals          True            Wake bouts < 16 s relabeled as state 5
  shuffled               True            Shuffled photometry plotted alongside
  shuffle_window         40              Chunk size for photometry shuffling
  window                 [50, 150] s     Pre/post transition plot window
  zscore                 False           Zeroed lifetime (not Z-scored)
  raw_lifetime           False           Use zeroed/normalized lifetime
  long_short_wake        True            Split Wake-NREM by preceding bout length
  long_short_NREM        True            Split NREM-Wake by preceding bout length
  NREM_cutoff            70 s            Bout length threshold for NREM split
  wake_cutoff            100 s           Bout length threshold for Wake split
  filter_bounds          [None, None]    No bandpass filtering
  p2                     True            Parameter passed to build_classes

                           [50,75]
