PURPOSE
-------
Computes sound-triggered FLiP lifetime (zeroed, not Z-scored) for four outcome
types (Wake-Wake, Sleep-Sleep, Sleep-Wake, Sleep-MA) in three mPFC FLIM-mAKAR
experiments. Compares experimental to shuffled data and runs nested statistics.
Produces Figure 3g and Extended Data Figure 3e for the manuscript.

Three recordings, 3 animals:

  Experiment ID                  Mouse ID
  ltFLiPAKARmemEEGEMG0016        3825
  ltFLiPAKARmemEEGEMG0066        4507
  ltFLiPAKARmemEEGEMG0071        4605

Raw file format: .mat files (concat*.mat) in each experiment folder.
Exclusion rule: First 3 acquisitions excluded; baseline range from spreadsheet.
Sound data: Bonsai audio-triggered .csv files in each experiment folder.


--------------------------------------------------------------------------------
PROCESSING PIPELINE
--------------------------------------------------------------------------------

Raw .mat files + Bonsai audio .csv (per experiment)
  |
  +--> choose_excluded_acqs()
  |      first_acqs = 3; pull_baseline = True from Excel.
  |
  +--> build_classes()
  |      sleep_states = True; microarousals = True; shuffled = True
  |      |
  |      +--> FLiPExperiment()  [called internally]
  |             Loads .mat, extracts FLiP lifetime, sleep states, shuffled trace.
  |
  +--> PKA.get_sound_timestamps()
  |      Reads Bonsai audio timestamps.
  |
  +--> PKA.find_photometry_audio_offset()
  |      Aligns audio triggers to photometry timebase.
  |
  +--> PKA.find_sound()
  |      Detects individual sound events in audio channel.
  |
  +--> PKA.soundframes_from_start()
  |      Converts sound event times to frames.
  |
  +--> PKA.sound_result()
  |      Packages sound events with outcome labels.
  |
  +--> PKA.sound_triggered_lifetime()
  |      Aligns zeroed FLiP lifetime to sound onset by outcome type.
  |      window = [50, 120] s; zscore = False
  |      these_outcomes = ['Wake-Wake', 'Sleep-Sleep', 'Sleep-Wake', 'Sleep-MA']
  |      shuffled = True (shuffled trace plotted alongside)
  |      color_dict = {k: '#00b47c' for k in these_outcomes}
  |      Returns: fig_dict, lifetime_dict
  |
  +--> transition_triggered_quant()   [per outcome]
  |      Quantifies amplitude in post-sound windows.
  |      Wake-Wake: [50,75]; Sleep-Wake: [50,75]; Sleep-MA: [10,30]
  |      Sleep-Sleep: [75,100]
  |
  +--> nested_analysis_stats_v2()   [experimental vs shuffled, per outcome]
         Stage 1: robust HuberT per-animal means.
         Stage 2: sign permutation test (primary) + Welch t-test (secondary).
         Sleep-Wake result: p = 0.0875; Sleep-MA result: p = 0.1964
