PURPOSE
-------
Compares FLiP lifetime change during sleep deprivation (SD) versus a matched
baseline wake window for 6 mPFC FLIM-mAKAR experiments. For SD, the longest
continuous wake bout in each recording is identified as the SD period. For
baseline, a wake bout within a fixed ZT4–ZT8 window is used. Plots FLiP
lifetime traces across each SD bout and a paired before/after amplitude change
comparison (SD vs baseline). Produces Extended Data Figure 5g for the
manuscript.

PROCESSING PIPELINE
--------------------------------------------------------------------------------

Raw .mat files
  |
  +--> build_classes()   [called twice — once per context, same EXP_NAMES]
  |      sleep_states = True; microarousals = True; exclude_acqs = False
  |      shuffle_window = 200; emp_lifetime = False
  |      |
  |      +--> FLiPExperiment()  [called internally]
  |             Loads .mat, extracts FLiP lifetime, sleep states.
  |
  +--> [SD context — per animal]
  |      find_sd_bout()  [defined in notebook]
  |        Identifies longest continuous wake bout from FLP_exp.SleepStates.
  |        Returns: time vector, FLiP lifetime array, ZT time array.
  |      SD_WakeData[e]['Start Val'] = mean(lft[50–100 s])
  |      SD_WakeData[e]['End Val']   = mean(lft[last 50 s])
  |      AmpChange = End Val − Start Val
  |
  +--> [Baseline context — per animal]
  |      find_zt_window_start()  [defined in notebook]
  |        Finds index of ZT4–ZT8 window in FLP_exp.ZeitTime;
  |        handles multi-day recordings via gap detection.
  |      PKA.LFTvals_byState()
  |        Extracts FLiP lifetime by sleep state within the ZT window.
  |        time_range = [ZT4 start, ZT4 start + 4 hr]
  |      Selects first and last wake bouts of sufficient duration.
  |      Cntrl_WakeData[e]['Start Val'] / ['End Val'] computed same as SD.
  |
  +--> Results_ByAnimal
  |      Aggregates SD and baseline AmpChange per animal.
  |
  +--> [Figure: 2-panel]
         ax1: FLiP lifetime vs ZT time traces (one line per SD recording)
              colored by animal (magma colormap)
              x-axis = ZT time (hr), xlim = [0, 4]
         ax2: Paired plot (baseline vs SD), one line per animal
              y-axis = ΔBinding Fraction

--------------------------------------------------------------------------------
LOCALLY DEFINED FUNCTIONS
--------------------------------------------------------------------------------

  find_sd_bout(FLP_exp)
    Defined in: EDFig5g.ipynb, cell 2
    Purpose: Identifies the longest continuous wake bout (the SD period) in a
             recording by finding the longest run of SleepStates == 1.
    Returns: t (time relative to bout start), lft (FLiP lifetime),
             zt (ZT time), [lft_start, lft_end] indices.

  find_zt_window_start(FLP_exp, zt_start, zt_end, prefer_occurrence=2,
                       gap_threshold=100)
    Defined in: EDFig5g.ipynb, cell 2
    Purpose: Returns the photometry index for the start of a ZT time window.
             Handles multi-day recordings by splitting on large index gaps.
    prefer_occurrence: which occurrence of the window to use (1-indexed).
    Returns: index into FLP_exp.Time, number of occurrences found.

  gap_threshold          100             Index gap threshold for multi-day split
