PURPOSE
-------
Computes the change in FLiP lifetime (binding fraction) across individual NREM
bouts during the post-sleep-deprivation (post-SD) recovery period and compares
it to a ZT-matched control window from the same recordings. Sleep bouts are
extracted and binned by hour within the 6-hour post-SD window. Analysis is run
twice: once with microarousals absorbed into sleep (include_MA=True) and once
with MAs treated as arousal breaks (include_MA=False). Mouse-level Wilcoxon
signed-rank tests compare post-SD to control for each hour bin. Produces
Figure 5h and Extended Data Figure 5g for the manuscript.

--------------------------------------------------------------------------------
PROCESSING PIPELINE
--------------------------------------------------------------------------------

Raw .mat files
  |
  +--> build_classes()   [called twice with same EXP_NAMES — once per context]
  |      sleep_states = True; microarousals = True; exclude_acqs = False
  |      shuffle_window = 200; emp_lifetime = False
  |      |
  |      +--> FLiPExperiment()  [called internally]
  |             Loads .mat, extracts FLiP lifetime, sleep states.
  |
  +--> [SD window identification — per animal]
  |      find_zt_window()   [defined in notebook]
  |        ZT window: ZT0–ZT4 (sd_zt_start=0, sd_zt_duration=4 hr)
  |        prefer_occurrence = 2 (second ZT0–ZT4 block = first full recording day)
  |        Returns: start and end indices into FLP_exp.Time
  |      post_sd_start = ZT4 end time; post_sd_end = post_sd_start + 6 hr
  |      compute_wake_mean_bf()   [defined in notebook]
  |        Mean Lifetime during wake epochs in the post-SD window.
  |        Excludes the first skip_wake_epochs=8 sleep-scoring epochs of each
  |        wake bout to skip the arousal-onset transient.
  |
  +--> [ZT-matched control window — per animal]
  |      Target ZT range = mean post_sd_zeit_start across SD animals + 6 hr
  |      find_zt_window()  prefer_occurrence = 1 (first ZT occurrence = baseline)
  |      compute_wake_mean_bf()  computed in the control window
  |
  +--> extract_sleep_bouts()   [defined in notebook; run for each include_MA value]
  |      Identifies contiguous sleep bout boundaries in the post-SD / control window.
  |      REM always absorbed (never breaks a bout boundary).
  |      include_MA=True:  MA absorbed into sleep (only true-wake events break bouts)
  |      include_MA=False: MA breaks the bout; exclude_post_MA_epochs=4 sleep-scoring
  |                        epochs after each MA are excluded.
  |      include_REM=True: bouts can start/end with REM.
  |
  +--> compute_bout_deltas()   [defined in notebook]
  |      delta_mode = 'wakeavg': delta = bout_end_lft − wake_mean_bf
  |      (wake_mean_bf is the mean Lifetime during wake in the same time window)
  |      Assigns each delta to an hour bin (0–5) based on bout offset time.
  |
  +--> [Mouse-level aggregation]
  |      Per mouse, per condition (post_sd / control), per hour bin:
  |        mean across all bouts in that bin → one value per mouse per hour.
  |
  +--> scipy.stats.wilcoxon()   [per hour bin, per include_MA value]
  |      Paired signed-rank test: per-mouse mean post-SD vs control delta.
  |      Requires ≥ 2 mice with data in both conditions.
  |      Result: p-value + significance string.
  |
  +--> make_ladder()   [defined in notebook; called once per include_MA value]
         Ladder (line) plot: for each hour bin, draws gray lines connecting
         each mouse's control → post-SD mean delta.
         Overlay: scatter points per condition per mouse.
         Significance brackets drawn above significant hours (p < 0.05).
         Saves to FIG_DIR in all SAVE_FORMATS.

  gap_threshold          100             Index gap threshold for multi-day split
  SAVE_FIGS              True            Whether to save output figures
  SAVE_FORMATS           ['png', 'ps']   Output figure formats
  color_ctrl             '#0e5aff'       Blue (control condition)
  color_sd               '#b41f1f'       Red (post-SD condition)
