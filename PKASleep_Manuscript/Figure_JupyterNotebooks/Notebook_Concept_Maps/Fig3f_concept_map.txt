PURPOSE
-------
Verification and quality-control plots for sound detection in a single mPFC
FLIM-mAKAR experiment (ltFLiPAKARmemEEGEMG0016, mouse 3825). For each
acquisition, produces a four-panel figure showing: (1) EEG spectrogram,
(2) FLiP lifetime trace, (3) sleep state hypnogram, and (4) detected sound
windows as rectangle patches. Produces Figure 3f for the manuscript.


--------------------------------------------------------------------------------
DATA
--------------------------------------------------------------------------------

Source directory: /Volumes/yaochen/Active/Lizzie/FLP_data/
Brain region: mPFC; Sensor: FLIM-mAKAR

One experiment:

  Experiment ID                  Mouse ID
  ltFLiPAKARmemEEGEMG0016        3825

Raw file format: .mat files (concat*.mat) in experiment folder.
Exclusion rule: First 3 acquisitions excluded; baseline range from spreadsheet.
Sound data: Bonsai audio-triggered .csv files in experiment folder.
EEG sampling rate: 200 Hz.


--------------------------------------------------------------------------------
PROCESSING PIPELINE
--------------------------------------------------------------------------------

Raw .mat file + Bonsai audio .csv
  |
  +--> choose_excluded_acqs()
  |      first_acqs = 3; pull_baseline = True from Excel.
  |
  +--> build_classes()
  |      sleep_states = True; microarousals = True
  |      |
  |      +--> FLiPExperiment()  [called internally]
  |             Loads .mat, extracts FLiP lifetime and sleep states.
  |
  +--> PKA.get_sound_timestamps()
  |      Reads Bonsai audio timestamps from .csv.
  |      ts_format = "%m/%d/%Y %H:%M:%S.%f"
  |      bonsaifile_ts_format = "%Y-%m-%dT%H:%M:%S.%f"
  |
  +--> PKA.find_photometry_audio_offset()
  |      Aligns audio trigger timestamps to photometry timebase.
  |
  +--> PKA.find_sound()
  |      Identifies individual sound events in the audio channel.
  |      fsd = 400 Hz (audio digitization rate)
  |
  +--> PKA.soundframes_from_start()
  |      Converts sound event times to frames relative to acquisition start.
  |
  +--> PKA.sound_result()
  |      Packages sound detection results for plotting.
  |
  +--> [loop per acquisition]
         |
         +--> SWS_utils.plot_spectrogram()
         |      EEG spectrogram: fs=200Hz, 1–16Hz, window=10s, noverlap=9.9s
         |
         +--> [FLiP lifetime trace subplot]
         |
         +--> [sleep state raster subplot]
         |
         +--> [rectangle patches for each detected sound window]
                matplotlib.patches.Rectangle added to axis
