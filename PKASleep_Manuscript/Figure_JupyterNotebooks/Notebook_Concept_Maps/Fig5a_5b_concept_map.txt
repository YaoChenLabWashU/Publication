PURPOSE
-------
Computes wake probability as a function of z-scored FLiP lifetime and fits a
logistic regression model (predictors: PKA-SP, sleep duration, ZT time) for
21 mPFC FLIM-mAKAR experiments. Compares experimental wake probability to
shuffled controls using permutation tests and mixed linear models. Also sweeps
a range of waking thresholds to verify robustness. Produces Figures 5a and 5b
for the manuscript.

--------------------------------------------------------------------------------
PROCESSING PIPELINE
--------------------------------------------------------------------------------

Raw .mat files
  |
  +--> choose_excluded_acqs()
  |      first_acqs = 3; pull_baseline = True from Excel.
  |
  +--> build_classes()
  |      sleep_states = True; microarousals = True; shuffled = True
  |      |
  |      +--> FLiPExperiment()  [called internally]
  |
  +--> [loop per animal, per experiment]
  |      PKA.LFT_WakeSleepDistance()  [called twice per experiment]
  |        → get_wake_distance=True:  wake distance + z-scored PKA-SP per bout
  |        → get_sleep_distance=True: preceding NREM duration per bout
  |      MA_to_NREM=True; NREM_wake_only=False
  |      stats.zscore() applied per experiment within animal.
  |
  +--> ZT time binning
  |      bins = np.arange(0, 25, 2)  → 12 ZT categories (ZT0-ZT2 … ZT22-ZT24)
  |
  +--> PKA.plot_wake_probability()   [per animal]
  |      Bins z-scored PKA-SP into 8 bins, computes wake probability.
  |      waking_binsize = 16 s; num_LFT_bins = 9 (→ 8 bins)
  |      bin_edges from min–max z-scored lifetime (9 edges, 8 bins)
  |
  +--> PKA.WakeProb_PermutationTest()
  |      Tests whether log(wake probability) has significant slope vs position.
  |
  +--> smf.mixedlm()   [experimental and shuffled separately]
  |      Mixed linear model: log(wake_prob) ~ position, grouped by animal.
  |
  +--> [threshold sweep]
  |      wake_prob_range = np.arange(4, 180, 16)
  |      Repeats wake probability binning at each threshold to verify robustness.
  |
  +--> PKA.wake_prob_logreg()
         Full logistic regression: P(wake) ~ PKA-SP + sleep_duration + ZT_categories.
         standardized = False; gee = False
         Returns odds ratios, 95% CI, and likelihood ratio for each predictor.

KEY PARAMETERS
--------------------------------------------------------------------------------

  Parameter              Value               Meaning
  ---------------------  ------------------  ----------------------------------------
  epoch_len              4 s                 Sleep scoring epoch length
  microarousals          True                Wake bouts < 16 s relabeled as MA
  MA_to_NREM             True                Microarousals excluded from wake distance
  NREM_wake_only         False               All sleep states count as sleep
  shuffled               True                Shuffled photometry computed
  waking_binsize         16 s                Threshold duration to define a wake event
  num_LFT_bins           9                   Number of bin edges → 8 bins
  ZT bins                np.arange(0,25,2)   12 two-hour ZT categories
  wake_prob_range        np.arange(4,180,16) Threshold sweep range (s)
  standardized           False               Raw (not standardized) logistic regression
  gee                    False               Standard logistic regression, not GEE
