PURPOSE
-------
Loads pre-computed two-state model parameters for all 21 mPFC FLIM-mAKAR
experiments, extracts and plots Rising/Falling Tau and Asymptote distributions
(scatter + box), compares exponential vs linear model BIC across all animals,
and visualizes model fit scatter vs actual. Produces Figures 4a, 4b, and 4e
for the manuscript.

--------------------------------------------------------------------------------
PROCESSING PIPELINE
--------------------------------------------------------------------------------

{exp_rawdatdir}/par_variability/pars_baseline_*.npy  (pre-computed per experiment)
  |
  +--> np.load(pars_baseline_*.npy) per experiment
  |      Loads [B1, B2, S1, S2] parameter arrays.
  |      Rising Tau = B1; Falling Tau = B2
  |      Rising Asymptote = S1; Falling Asymptote = S2
  |
  +--> np.median() per experiment
  |      Median parameter across NREM bouts within each experiment.
  |
  +--> build_classes()   [for model fit scatter only]
  |      Constructs FLiPExperiment objects.
  |      |
  |      +--> FLiPExperiment()  [called internally]
  |
  +--> PKA.two_model_fit()   [per experiment]
  |      Fits two-state exponential model to FLiP lifetime using parameters.
  |
  +--> PKA.apply_model()
  |      Applies fitted model to data for scatter plot (fitted vs actual).
  |
  +--> PKA.gmm_cluster_pka()
  |      Clusters PKA-SP states using a Gaussian mixture model.
  |
  +--> PKA.find_continuous()
  |      Identifies contiguous NREM bouts from sleep state labels.
  |
  +--> [BIC analysis]
  |      np.load(exp_lin_fits.npy) per experiment
  |      Loads stored BIC values for exponential and linear fits.
  |      percent BIC diff = (BIC_lin - BIC_exp) / |BIC_exp| * 100
  |
  +--> scipy.stats.wilcoxon()
         One-sample Wilcoxon on percent BIC difference vs zero.
         Result: p = 9.5e-07
