PURPOSE
-------
Fits and compares exponential versus linear decay models to FLiP lifetime
traces from two contexts in FLIM-mAKAR mPFC experiments: (1) following
scopolamine injection (ED Fig 1e), and (2) during spontaneous sustained NREM
bouts (ED Fig 1f). Uses BIC to determine which model better describes
dephosphorylation kinetics. Statistics compare exponential decay constants
(log-transformed) between injection and baseline conditions.

--------------------------------------------------------------------------------
PROCESSING PIPELINE
--------------------------------------------------------------------------------

Raw .mat files + injection_info.json
  |
  +--> choose_excluded_acqs()
  |      first_acqs = 0; no acquisitions dropped.
  |
  +--> build_classes()
  |      Constructs FLiPExperiment objects.
  |      |
  |      +--> FLiPExperiment()  [called internally]
  |             Loads concatenated .mat file, extracts FLiP lifetime,
  |             applies sleep scoring and microarousal labeling.
  |
  +--> FLP_exp.add_drug_epochs()
  |      Adds epoch labels (EpochID): 1=saline, 2=drug, using injection_info.json.
  |      post_injection_buffer = 100 s
  |
  +--> [Injection context — ED Fig 1e]
  |      For each acquisition containing EpochID == 2:
  |        savgol_filter(LFT, 11, 2)
  |        curve_fit(exponential_model, t-t[0], filt_LFT) → popt_exp, BIC_exp
  |        curve_fit(linear_model, t-t[0], filt_LFT)      → popt_lin, BIC_lin
  |        BIC = n * log(SSE/n) + k * log(n)
  |
  +--> [Baseline NREM context — ED Fig 1f]
  |      FLP_exp.ss_onset_offset() on merged sleep states (REM → NREM)
  |      Filter NREM bouts: duration > 100 s, preceding wake > 75 s
  |      savgol_filter → curve_fit exponential + linear → BIC
  |
  +--> group_by_animal()  [defined in notebook]
  |      Groups log(b) from exponential fits by animal, filtering NaN/inf.
  |
  +--> FLPstats.nested_analysis_stats_v2()
         Stage 1: robust HuberT per-animal means.
         Stage 2: sign permutation test (primary) + paired t-test (secondary).

    Defined in: EDFig1e_ED1f.ipynb, cell 2
    Formula: a * exp(-b * x) + c
    Used for: fitting dephosphorylation traces; b = decay rate, 1/b = time constant

  linear_model(x, m, c)
    Defined in: EDFig1e_ED1f.ipynb, cell 2
    Formula: m * x + c
    Used for: BIC comparison against exponential

  group_by_animal(pars_list, animal_list)
    Defined in: EDFig1e_ED1f.ipynb, cell 10 (nested_flpstats_v2 cell)
    Purpose: Strips NaN entries from pars_list, groups log(b) values by animal.
    Returns: dict mapping animal ID → list of log(decay rate) values
