PURPOSE
-------
Plots a PhosphoPlot for a single mPFC FLIM-mAKAR experiment
(ltFLiPAKARmemEEGEMG0094, mouse 4775), showing the instantaneous binding
fraction as a density scatter plot with a phase-portrait-style layout.
Produces Extended Data Figure 4f for the manuscript.


--------------------------------------------------------------------------------
DATA
--------------------------------------------------------------------------------

Source directory: /Volumes/yaochen/Active/Lizzie/FLP_data/
Baseline indices: /Users/lizzie/Library/CloudStorage/Box-Box/ChenLab/Lizzie/
                  FLiP_Experiment_Summary.xlsx

One experiment:

  Experiment ID                  Mouse ID
  ltFLiPAKARmemEEGEMG0094       4775

Raw file format: .mat files (concat*.mat) in experiment folder.
Exclusion rule: First 3 acquisitions excluded; baseline range from spreadsheet.
Sleep scoring: Not applied (sleep_states = False).


--------------------------------------------------------------------------------
PROCESSING PIPELINE
--------------------------------------------------------------------------------

Raw .mat file
  |
  +--> pd.read_excel(FLiP_Experiment_Summary.xlsx)
  |      Reads baseline acquisition range for this experiment.
  |
  +--> choose_excluded_acqs()
  |      first_acqs = 3; pull_baseline = True using baseline_idxs from Excel.
  |
  +--> build_classes()
  |      Constructs a FLiPExperiment object without sleep scoring.
  |      |
  |      +--> FLiPExperiment()  [called internally]
  |             Loads concatenated .mat file, extracts FLiP lifetime.
  |             sleep_states = False: no sleep scoring is performed.
  |
  +--> PKA.PhosphoPlot()
         Generates a density scatter plot of instantaneous binding fraction
         (FLP_exp.Lifetime) with customizable arrow scale and transparency.
         filterbin_width = 40, scale = 8, alpha = 1
         headwidth = 3, headlength = 4, headaxislength = 3.5, width = 0.002
         Returns updated (fig, ax).

  fig.savefig(os.path.join(FLP_exp.rawdatdir, 'PhosPhoplot' + b + fig_ext))
