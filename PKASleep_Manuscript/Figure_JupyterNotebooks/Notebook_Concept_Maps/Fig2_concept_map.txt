PURPOSE
-------
Plots transition-triggered FLiP lifetime (zeroed, not Z-scored) across four
brain regions (Dorsal CA1, Motor Cortex, Visual Cortex, mPFC) using FLIM-mAKAR,
comparing experimental to shuffled data within each region and splitting NREM-Wake
transitions by bout length. Also runs nested statistical analyses per region and
transition type. Produces Figure 2 for the manuscript. Parallel notebook to
EDFig3.ipynb; uses same data but different visualization parameters.

--------------------------------------------------------------------------------
PROCESSING PIPELINE
--------------------------------------------------------------------------------

Raw .mat files (per brain region)
  |
  +--> choose_excluded_acqs()
  |      first_acqs = 3; pull_baseline = True from Excel.
  |
  +--> build_classes()   [called per region, microarousals=True, p2=True]
  |      Constructs FLiPExperiment objects.
  |      |
  |      +--> FLiPExperiment()  [called internally]
  |             Loads .mat, extracts FLiP lifetime, sleep states, MAs.
  |
  +--> transition_triggered_lifetime()   [per region, shuffled=True]
  |      Aligns zeroed FLiP lifetime to sleep state transitions.
  |      Transitions: NREM-Wake, REM-Wake, Microarousals, Wake-NREM, NREM-REM
  |      shuffle_window = 40 s
  |      window = [50, 150] s; NREM_cutoff = 70 s; wake_cutoff = 100 s
  |      zscore = False; long_short_NREM = True; long_short_wake = True
  |      Returns: fig_dict (separate per region)
  |
  +--> transition_triggered_quant()   [per region, per transition]
  |      Quantifies amplitude in post-transition windows.
  |
  +--> nested_analysis_stats_v2()   [experimental vs shuffled, per region]
         Stage 1: robust HuberT per-animal means.
         Stage 2: sign permutation test (primary) + Welch t-test (secondary).
         Note: mPFC uses perm_flag = False.

--------------------------------------------------------------------------------
KEY PARAMETERS
--------------------------------------------------------------------------------

  Parameter              Value           Meaning
  ---------------------  --------------  ----------------------------------------
  epoch_len              4 s             Sleep scoring epoch length
  microarousals          True            Wake bouts < 16 s relabeled as MA
  shuffled               True            Shuffled photometry plotted alongside
  shuffle_window         40 s            Chunk size for photometry shuffling
  window                 [50, 150] s     Pre/post transition plot window
  zscore                 False           Zeroed lifetime (not Z-scored)
  long_short_wake        True            Split Wake-NREM by preceding bout length
  long_short_NREM        True            Split NREM-Wake by preceding bout length
  NREM_cutoff            70 s            Bout length threshold for NREM split
  wake_cutoff            100 s           Bout length threshold for Wake split
  p2                     True            Parameter passed to build_classes
  region_colors          CA1: '#ff9408'  Color per brain region
                         Motor: '#9d0085'
                         Visual: '#0089f4'
                         mPFC: '#00b47c'
