PURPOSE
-------
Plots stimulation-triggered binding fraction traces for the biPAC sensor at
four stimulation pulse lengths (10, 100, 500, 1000 ms) at a fixed light power
(100.5 µW). Traces are shown as mean ± SEM of ΔBinding fraction (change from
pre-stimulus baseline). Produces Extended Data Figure 1d for the manuscript.


--------------------------------------------------------------------------------
DATA
--------------------------------------------------------------------------------

Source file: /Volumes/yaochen/Active/zach/flip/multi_exp_traces_dict.npy

Pre-computed dictionary containing:
  Key                  Contents
  -------------------  -------------------------------------------------------
  traces               List of binding fraction trace arrays (one per trial)
  time                 Time vector (seconds) relative to stimulation onset
  stim_power(uW)       Stimulation power in µW for each trial
  stim_length          Stimulation pulse duration in ms for each trial

No FLiPExperiment class is constructed; data are loaded directly from the
pre-computed .npy file produced by Zach's pipeline.

Filter applied: stim_power(uW) == 100.5 µW
Grouping: by stim_length (10, 100, 500, 1000 ms)
